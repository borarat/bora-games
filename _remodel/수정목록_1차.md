## 교과서 기준 (비상교육 박현숙, 교사 제공 '쏙쏙! 개념 정리' — 음운 게임은 이 용어·분류에 맞춘다)

- 소리 나는 위치: 입술소리 ㅂ ㅃ ㅍ ㅁ / 잇몸소리 ㄷ ㄸ ㅌ ㅅ ㅆ ㄴ ㄹ / 센입천장소리 ㅈ ㅉ ㅊ / 여린입천장소리 ㄱ ㄲ ㅋ ㅇ / 목청소리 ㅎ
- 소리 내는 방법: 울림소리 — 비음(콧소리) ㄴ ㅁ ㅇ, 유음(흐름소리) ㄹ / 안울림소리 — 파열음 ㄱ ㄲ ㅋ ㄷ ㄸ ㅌ ㅂ ㅃ ㅍ, 마찰음 ㅅ ㅆ ㅎ, 파찰음 ㅈ ㅉ ㅊ
- 소리의 세기: 예사소리 ㄱ ㄷ ㅂ ㅅ ㅈ / 된소리 ㄲ ㄸ ㅃ ㅆ ㅉ / 거센소리 ㅋ ㅌ ㅍ ㅊ
- **ㅎ은 세기 분류에 넣지 않는다.** (교과서 참고 자료: 학자에 따라 거센소리 또는 예사소리로 본다) → ㅎ의 세기를 묻는 문항은 빼고, 세기 단계에 ㅎ이 나오면 제외한다
- 게임 안의 용어가 위와 다르면(예: '연구개음') 교과서 용어로 맞춘다. 괄호 병기는 교과서처럼 '비음(콧소리)'

각 게임의 **'고칠 것'만 고친다. '고치지 말 것'은 교사가 의도한 설계라 절대 바꾸지 않는다.**
'확인'이 있으면 고치지 말고 보고서에 질문으로 남긴다.
작업 파일은 저장소의 사이트 경로 파일이다(이미 최신판).

## 1. G201 단모음 갤러그 — games/문법/단모음_갤러그_게임_1.html (버그만)

**고칠 것**
- 정답률이 '그냥 통과시킨 비목표'를 맞힘으로 센다(767·772행 부근). 한 발도 안 쏴도 약 50%다. 맞힌 목표 ÷ (나온 목표 + 잘못 쏜 비목표)로
- 잘못 쏨 감점(−5)을 명중 득점(+10)과 같게 한다(v3.1 속도형 규칙)
- 시작 화면에도 ㅚ·ㅟ는 이중 모음으로도 발음할 수 있다는 한 줄 안내
- '게임 끝내기'에 확인 단계

**고치지 말 것**: 목표 모음 목록·기준 버튼, 쉬운 난이도, 반복 출제

## 1-2. G202 자음 체계 구분하기 — games/문법/자음_체계_구분하기_3.html (내용 작음)

**고칠 것**
- ㅎ을 예사소리로 출제한 문항(518·561행 부근)을 뺀다. 세기 단계에서 ㅎ이 나오지 않게 한다 (위 교과서 기준)
- 초성 ㅇ은 소리가 없다는 안내를 한 줄 넣는다(ㅇ이 비음으로 나오는 곳에). 여린입천장소리·비음의 ㅇ은 받침 [ŋ] 소리다
- 위치·방법 분류와 용어가 위 교과서 표와 같은지 대조하고, 다르면 맞춘다(바꾼 것은 보고서에 전부)

**고치지 말 것**: 울림 단계 '안울림' 비율, 2지선다 재도전, 감점 10점, 반복 출제

## 2. G207 단모음 두더지 탭 — games/문법/단모음_두더지_게임.html (버그만)

## 3. G203 음운 체계 메모리 게임 — games/문법/음운체계_메모리게임_리모델링.html (버그만)

**고칠 것**
- 짝이 맞으면 한 줄 설명을 띄운다(지침 3-6). 설명은 기존 해설·카드 내용에서 가져오고, 새 개념 설명을 만들면 보고서에 전부 적는다
- 격려 문구 기준: 60%인데 '완벽'이 뜬다. 지침 5-2 표에 맞춘다
- 오답 목록을 원본 id로 전송

**고치지 말 것**: '전체 보기' 여러 번(의도), 모둠 대항 운영 방식, 카드 구성

## 4. G205 잘못된 피동 표현 맞추기 — games/문법/피동-잘못된_피동_맞추기_리모델링.html (내용 작음)

**고칠 것**
- 제목·머리글·게임 이름·JPG 제목의 '맞추기' → '맞히기' (사이트 파일 경로는 바꾸지 않는다)
- 올바른 피동(CORRECT) 목록의 자동사 2문항을 **교사 승인된 문장으로** 교체한다 (id는 그대로):
  - C19 '멀리서 종소리가 은은하게 울린다.' → '산책하다가 모기에게 팔을 물렸다.' / 해설: "'물리다' = 물다 + -리-. 접미사 하나만 쓴 올바른 피동."
  - C23 '창밖으로 아름다운 풍경이 비쳤다.' → '꽁꽁 묶였던 매듭이 드디어 풀렸다.' / 해설: "'풀리다' = 풀다 + -리-. '묶이다'도 접미사 하나만 쓴 올바른 피동."
- 잘못 쏜 풍선이 정답률 분모에서 빠져 전부 쏘면 100%. 분모에 넣는다
- 오발사 감점을 명중 득점과 같게(속도형)

**확인 끝남 — 그대로 둔다**: C12 '밝혀졌다' 해설, S20 '잠겨져'

**고치지 말 것**: 쉬운 난이도, 반복 출제, 힌트
