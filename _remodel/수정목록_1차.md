# 1차 야간 리모델링 대상 (2026-10-01 새벽)

각 게임의 **'고칠 것'만 고친다. '고치지 말 것'은 교사가 의도한 설계라 절대 바꾸지 않는다.**
'확인'이 있으면 고치지 말고 보고서에 질문으로 남긴다.
작업 파일은 저장소의 사이트 경로 파일이다(이미 최신판).

---

## 1. G201 단모음 갤러그 — games/문법/단모음_갤러그_게임_1.html (버그만)

**고칠 것**
- 정답률이 '그냥 통과시킨 비목표'를 맞힘으로 센다(767·772행 부근). 한 발도 안 쏴도 약 50%다. 맞힌 목표 ÷ (나온 목표 + 잘못 쏜 비목표)로
- 잘못 쏨 감점(−5)을 명중 득점(+10)과 같게 한다(v3.1 속도형 규칙)
- 시작 화면에도 ㅚ·ㅟ는 이중 모음으로도 발음할 수 있다는 한 줄 안내
- '게임 끝내기'에 확인 단계

**고치지 말 것**: 목표 모음 목록·기준 버튼, 쉬운 난이도, 반복 출제

## 2. G207 단모음 두더지 탭 — games/문법/단모음_두더지_게임.html (버그만)

**고칠 것**
- ㅚ·ㅟ 이중 모음 발음 허용 안내 한 줄
- '게임 끝내기'에 확인 단계
- (속도형 규칙) 잘못 누름 감점이 맞힘 득점보다 작으면 같게 맞춘다

**고치지 말 것**: 목표 모음 목록 3곳(기준 버튼·시작 배너·'이번 목표' 카드). 보면서 익히는 연습용이다

## 3. G203 음운 체계 메모리 게임 — games/문법/음운체계_메모리게임_리모델링.html (버그만)

**고칠 것**
- 짝이 맞으면 한 줄 설명을 띄운다(지침 3-6). 설명은 기존 해설·카드 내용에서 가져오고, 새 개념 설명을 만들면 보고서에 전부 적는다
- 격려 문구 기준: 60%인데 '완벽'이 뜬다. 지침 5-2 표에 맞춘다
- 오답 목록을 원본 id로 전송

**고치지 말 것**: '전체 보기' 여러 번(의도), 모둠 대항 운영 방식, 카드 구성

## 4. G205 잘못된 피동 표현 맞추기 — games/문법/피동-잘못된_피동_맞추기_리모델링.html (내용 작음)

**고칠 것**
- 제목·머리글·게임 이름·JPG 제목의 '맞추기' → '맞히기' (사이트 파일 경로는 바꾸지 않는다)
- '울린다', '비쳤다'를 올바른 피동으로 분류했다(자동사). 다른 올바른 피동 표현으로 교체한다 — 교체 문항은 보고서에 표로 적어 교사 승인을 받는다
- 잘못 쏜 풍선이 정답률 분모에서 빠져 전부 쏘면 100%. 분모에 넣는다
- 오발사 감점을 명중 득점과 같게(속도형)

**확인**: C12 해설 "'밝히다'는 사동사", S20 '잠기다' — 고치지 말고 질문으로

**고치지 말 것**: 쉬운 난이도, 반복 출제, 힌트
