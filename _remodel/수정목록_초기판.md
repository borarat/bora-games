# 음운 체계 익히기 초기판 → 순수 HTML로 다시 만들기 (G212)

원본: _remodel/원본/음운체계익히기_초기판.html (React·Tailwind·Babel·lucide·confetti CDN 6개. 인터넷 없으면 안 열림)
결과 파일: games/문법/음운체계_익히기.html (새 파일. games.html 목록에는 넣지 않는다 — 교사 승인 후 추가)
게임 코드: G212

## 방침
- 원본의 게임 구성(체계표 빈칸 채우기 + 음절 조립, 4단계)과 문항·흐름을 **그대로 옮긴다**. 새 활동을 만들지 않는다
- 외부 스크립트 없이 순수 HTML/CSS/JS 단일 파일. 화면·연출은 _remodel/지침/학습게임_화면연출표준_v3.md를 따른다
- 교과서 자음 체계 기준은 _remodel/수정목록_1차.md 맨 위 절을 따른다 (ㅎ은 세기 분류에서 제외)

## 고칠 것 (내용)
- '욀'의 초성 ㅇ을 비음으로 설명한 부분. 초성 ㅇ은 소리가 없다
- '톺'의 받침 ㅍ을 거센소리로 설명한 부분. 받침 ㅍ은 [ㅂ]으로 소리 난다
- 받침 ㄱ을 "터뜨리면서"로 설명한 부분(켁·쏙·책). 받침에서는 터뜨리지 않는다
- ㅎ의 세기를 묻는 문항은 뺀다
- 용어를 교과서 표에 맞춘다(입술소리·잇몸소리·센입천장소리·여린입천장소리·목청소리, 비음(콧소리)·유음(흐름소리)·파열음·마찰음·파찰음)
- 성취기준 표기는 지침 2-4(2022·2015 병기)에 맞춘다. 원본 문구 [9국04-10]은 보고서에 그대로 적고 확인 질문으로 남긴다

## 고치지 말 것
