# 국어 개념 판정 기준표 (v1 · 2026.09.30)

> 프로젝트 지식 파일. 게임끼리 같은 개념을 같은 기준으로 판정하기 위한 기준이다.
> 27종 게임을 검토하며 **게임마다 판정이 달랐거나 틀렸던 지점**을 중심으로 정리했다.
>
> - **【확인 필요】** 표시는 교과서·학자마다 갈리는 항목이다. 비상교육(박현숙) 교과서로 확인해 이 파일을 고친 뒤 쓴다. 확인 전에는 연습 문항에서 뺀다
> - 이 파일과 다르게 판정해야 하면 멈추고 교사에게 묻는다
> - 새 개념을 판정했으면 완료 보고에서 이 파일에 추가할 항목으로 알린다

## 1. 음운

### 1-1. 단모음 (10개)

| | 전설 · 평순 | 전설 · 원순 | 후설 · 평순 | 후설 · 원순 |
|---|---|---|---|---|
| 고모음 | ㅣ | ㅟ | ㅡ | ㅜ |
| 중모음 | ㅔ | ㅚ | ㅓ | ㅗ |
| 저모음 | ㅐ | | ㅏ | |

- ㅚ·ㅟ는 이중 모음으로 발음하는 것도 허용된다 (표준 발음법 제4항 붙임). 시작 화면이나 입술 모양 힌트에서 한 줄 안내한다. 학생이 [we]로 발음하면 입술이 모였다 펴지는 것을 느끼므로 혼동한다
- 해설은 결론 반복 대신 비교로 쓴다: "ㅣ-ㅔ-ㅐ 순서로 발음하면 입이 점점 벌어진다", "ㅣ를 발음한 채 입술만 둥글게 모으면 ㅟ"

### 1-2. 자음 (19개)

| 조음 방법 \ 위치 | 입술소리 | 잇몸소리 | 센입천장소리 | 여린입천장소리 | 목청소리 |
|---|---|---|---|---|---|
| 파열음 | ㅂ ㅃ ㅍ | ㄷ ㄸ ㅌ | | ㄱ ㄲ ㅋ | |
| 마찰음 | | ㅅ ㅆ | | | ㅎ |
| 파찰음 | | | ㅈ ㅉ ㅊ | | |
| 비음 | ㅁ | ㄴ | | ㅇ | |
| 유음 | | ㄹ | | | |

- 자음 가운데 울림소리는 **ㄴ ㄹ ㅁ ㅇ** 4개뿐이다 (모음은 모두 울림소리). 울림 문항은 울림소리 4개가 모두 나오고 비율을 맞춘다 (전부 '안울림'만 골라도 맞는 구조 금지)
- ㅇ은 받침에서만 [ŋ]으로 소리 난다. 초성 ㅇ은 소리가 없다는 점을 안내한다
- **ㅎ의 세기(예사소리·거센소리) 분류 【확인 필요】** — 교과서 자음 체계표에서 ㅎ이 세기 어느 칸에 있는지 확인한다. 확인 전에는 세기 문항에서 ㅎ을 뺀다
- 울림 여부 힌트로 "목에 손을 대 보라"를 쓸 때는 **이어서 낼 수 있는 소리끼리** 비교한다: ㅁ·ㄴ(콧노래처럼 '음—', '은—')은 울리고 ㅅ·ㅎ('스—', '흐—' 바람 소리)은 울리지 않는다. ㄱ·ㄷ·ㅂ 같은 파열음은 모음 없이 낼 수 없어 이 방법으로 확인할 수 없다. '기역'처럼 이름으로 읽으면 모음 때문에 늘 울린다
- 세기 해설은 비교형으로 쓴다: "ㄷ / ㄸ / ㅌ을 차례로 발음하며 입 앞에 손바닥을 대 보면 ㅌ에서 바람이 가장 세다"

## 2. 단어

### 2-1. 단어의 짜임 — 합성어와 파생어

- 판정은 **직접 구성 요소** 둘로 먼저 나눈 뒤 한다
  - 어근 + 어근 → 합성어 / 어근 + 접사 → 파생어
- **연습 문항에서 빼는 것**
  - 활용형: 슬프게, 작게(어미 '-게'), 빠름, 가벼움(명사형 어미 '-(으)ㅁ'으로 사전 표제어가 아닌 것)
  - 한자어 조어: 강산, 가로등, 편의점 【교과서가 한자어를 다루는지 확인 필요】
  - 판단이 갈리는 말: 길잡이, 돌덩이
- **늦-(늦가을·늦잠·늦더위) 【확인 필요】** — 사전에는 접두사 '늦-'이 있지만, 교과서는 늦잠·늦더위를 '덮밥'과 같은 비통사적 합성어의 예로 자주 든다. 교과서 처리를 확인하기 전에는 문항에서 뺀다
- 파생명사와 명사형 활용 구별: 사전 표제어이고 앞에서 부사가 꾸밀 수 없으면 파생명사(슬픔, 믿음, 젊음, 달리기 대회), 서술 기능이 있고 부사가 꾸밀 수 있으면 활용형(빨리 달리기가 어렵다)

**자주 틀린 접사** (이 말이 붙으면 파생어)

| 구분 | 예 |
|---|---|
| 접두사 | 맏-(맏형), 헛-(헛소리·헛기침), 덧-(덧문·덧신), 풋-(풋고추), 햇-(햇나물), 맨-(맨손), 잔-(잔소리), 찰-(찰떡), 민-(민소매), 한-(한여름), 치-(치솟다), 새-/샛-/시-(새빨갛다·샛노랗다·시퍼렇다) |
| 접미사 | -꾼(노래꾼), -쟁이(고집쟁이·겁쟁이), -꾸러기, -질(부채질), -개(덮개·지우개), -이(먹이·높이), -기(달리기), -(으)ㅁ(슬픔·믿음), -껏(힘껏), -롭다(새롭다), -되다(참되다) |

**좋은 경계 쌍** (해설에 이유를 반드시 쓴다)

| 합성어 | 파생어 | 이유 |
|---|---|---|
| 햇살 (해 + 살) | 햇나물 (햇- + 나물) | '햇살'의 '해'는 명사, '햇나물'의 '햇-'은 '그해에 난'이라는 뜻의 접두사 |
| 덮밥 (덮- + 밥) | 덮개 (덮- + -개) | 밥은 어근, -개는 접미사 |

### 2-2. 품사

- 9품사를 쓴다. '5언'은 교과서 용어가 아니다 → 교과서 표현(체언·용언·수식언·관계언·독립언)을 쓴다 【교과서 표기 확인】
- 수사와 관형사: **체언을 꾸미면 관형사**(세 개, 첫째 줄), 꾸미지 않고 조사가 붙는 자리에 오면 **수사**(셋이 왔다, 셋 왔다, 첫째가 되었다). 조사가 생략되어도 수사다
- "9품사는 의미에 따른 분류"라고 단정하지 않는다. 형태·기능·의미의 세 기준으로 나눈다 【교과서 설명 문구 확인】

### 2-3. 동사와 형용사

판별 검사 (해설·힌트에 이 검사를 쓴다)

1. **현재형 '-는다/-ㄴ다'가 붙는가** → 붙으면 동사 (먹는다 ○ / 작는다 ×). 기본 검사로 쓴다
2. 명령형 '-아라/-어라', 청유형 '-자'가 자연스러운가 → 보조 검사. 동사라도 명령이 어색한 말이 있다
3. 관형사형 '-는'은 판별 검사로 쓰지 않는다. '있다·없다·계시다'는 '-는'이 붙어도(없는, 있는) 형용사로 보거나 따로 다루기 때문이다

**경계 사례** (단계마다 넣는다)

| 말 | 판정 |
|---|---|
| 크다 | '키가 크다'는 형용사, '아이가 쑥쑥 큰다(자라다)'는 동사 |
| 밝다 | '방이 밝다'는 형용사, '날이 밝는다'는 동사 |
| 늦다 | '시간이 늦다'는 형용사, '약속에 늦는다'는 동사 |
| 맞다 | 동사 (맞는다, 맞는 답) |
| 없다 | 형용사 |
| 있다 | 【확인 필요】 '머무르다' 뜻은 동사, '존재하다' 뜻은 형용사로 보는 설명이 일반적이다. 교과서 처리를 확인하고, 확인 전에는 문항에서 뺀다 |

## 3. 문장

### 3-1. 문장 성분 (7개)

| 성분 | 기준 |
|---|---|
| 주어 | 서술어의 주체. '이/가, 께서'가 대표. **보조사가 붙어도 주어**(나는, 너도) |
| 서술어 | |
| 목적어 | '을/를'이 대표. **보조사가 붙거나 조사가 생략돼도 목적어**(밥도 먹었다, 밥 먹었다) |
| 보어 | **'되다, 아니다' 앞에서 서술어를 보충하는 말** (물이 얼음이 되었다, 그는 학생이 아니다). 대표 조사는 '이/가'지만 **보조사가 붙거나 조사가 생략돼도 보어**(얼음은 되지 않았다, 학생 아니다) |
| 관형어 | 체언을 꾸밈 |
| 부사어 | 용언 등을 꾸밈. **필수적 부사어**가 있다 (닮았다·같다·삼다·넣다·주다 등이 요구하는 부사어) |
| 독립어 | 감탄사, 부름말 |

- 조사만 보고 판정하는 습관을 깨는 문항(보조사, 조사 생략, 필수적 부사어, 보어)을 단계마다 넣는다
- 힌트 예: "빼도 문장이 성립하나요?", "'되다/아니다' 앞인가요?"

### 3-2. 안은문장 — 절의 종류

| 절 | 표지 | 예 |
|---|---|---|
| 명사절 | -(으)ㅁ, -기 | 그가 범인임이 밝혀졌다 |
| 관형절 | -(으)ㄴ, -는, -(으)ㄹ, -던 | 내가 어제 산 책 |
| 부사절 | -이(없이, 달리), -게, -도록, -듯이 | 소리도 없이 눈이 내렸다 |
| 서술절 | 표지 없음. 주어가 둘 | 코끼리는 코가 길다 |
| 인용절 | 직접 '라고', 간접 '고' | 그는 비가 온다고 말했다 |

- **절에는 그 절의 주어가 포함된다.** 밑줄을 칠 때 절의 주어를 빠뜨리지 않는다 (할머니가 직접 짜신 → '할머니가'까지 절)
- 명사절이 문장에서 어떤 성분인지는 **조사가 아니라 서술어와의 관계**로 판정한다. '그 영화가 재미있음은 누구나 인정한다'에서 명사절은 목적어(보조사 '은'이 '을' 자리에 옴), 주어는 '누구나'
- 조사를 적을 때 붙임표를 쓰지 않는다 ('-고'가 아니라 '고'). 붙임표는 어미·접사에만
- '-는 것' 구성(그가 온 것을 알았다)의 처리 【확인 필요】 — 학교문법은 관형절 + 의존 명사로 본다. 교과서가 명사절처럼 다루는지 확인하고, 확인 전에는 절 종류 문항에서 뺀다
- **'-게, -도록, -듯이'를 부사절 어미로 볼지 종속적 연결 어미로 볼지 【확인 필요】** — 교과서마다 다르다. 확인 전에는 부사절 문항은 '-이(없이, 달리)' 예만 쓰고, 이 어미들은 부사절 문항과 이어진 문장 문항 모두에서 뺀다

### 3-3. 이어진 문장

| 종류 | 대표 연결 어미 |
|---|---|
| 대등적 | -고(나열), -(으)며, -지만, -(으)나, -거나, -든지 |
| 종속적 | -아서/-어서, -(으)니까, -(으)면, -(으)려고 |

- 판별 검사 (학생이 직접 해 보는 문항을 넣는다)
  1. 앞뒤 절을 바꿔도 뜻이 같은가 → 같으면 대등
  2. 앞 절을 뒤 절 속으로 옮길 수 있는가 → 되면 종속
- **'-고'는 둘 다 가능하다.** 나열(바람이 불고 비가 온다)은 대등, 시간 순서(밥을 먹고 학교에 갔다)는 종속으로 보는 설명이 일반적이다 【교과서 처리 확인】. '-고 = 대등'으로 단정하는 문항·해설을 쓰지 않는다
- **'-는데'도 둘 다 가능하다 【확인 필요】** — 배경·상황 제시(비가 오는데 우산이 없다)는 종속, 대조(형은 큰데 동생은 작다)는 대등으로 보기도 한다. 확인 전에는 문항에서 뺀다
- '-도록'은 3-2의 【확인 필요】에 따른다
- 예문 시제를 자연스럽게 쓴다 (밤을 새우니 오늘 졸리다 × → 밤을 새웠더니 오늘 졸리다)

## 4. 피동 표현

### 4-1. 기본

| 방법 | 예 |
|---|---|
| 피동 접미사 -이-, -히-, -리-, -기- | 보이다, 잡히다, 들리다, 안기다 |
| -아지다/-어지다 | 만들어지다, 지워지다, 올려지다 |
| -되다 (일부 명사 + 되다) | 변경되다, 결정되다 |

- **정의는 교과서 문구**: "피동 표현: 주어가 다른 대상에게 동작이나 행위를 당하는 것을 나타내는 표현."(비상교육). 다만 문항 해설은 형식 근거로 쓴다: "'잡히다'는 '잡다'에 피동 접미사 '-히-'가 붙은 말. 능동문의 목적어(도둑을)가 주어(도둑이)가 되고, 능동문의 주어(경찰이)는 '경찰에게'가 되거나 생략되었다"
- 접미사는 **어간 끝소리로 정해지지 않는다** (먹히다/섞이다, 막히다/깎이다). "끝소리를 보면 알 수 있다"는 힌트 금지. 힌트는 "붙여서 소리 내 보고 자연스러운 말을 고르세요"
- 어간이 바뀌는 예(가두다 → 갇히다)는 해설에 예외라고 밝히거나 문항에서 뺀다
- 능동문·피동문 쌍은 **같은 사건을 가리키게** 만든다

### 4-2. 피동이 아닌 것

| 말 | 판정 |
|---|---|
| 풍경이 비친다, 종이 울린다, 열매가 열린다 | 자동사. 피동 예문으로 쓰지 않는다. (단 '문이 열린다'의 '열리다'는 '열다'의 피동사로, 교과서의 대표 피동 예문이다) |
| 날씨가 풀렸다, 감기에 걸렸다 | 대응하는 능동문이 없다. 연습 문항에서 뺀다 |
| 매진되다, 통과되다 | 대응 능동문이 어색하다. 연습 문항에서 뺀다 |
| 중단시키다, 먹이다(아이에게 밥을), 읽히다(학생에게 책을) | **사동**. 목적어가 있고 남에게 시키는 뜻. 능동으로만 처리하지 말고 사동과 구별하는 문항으로 쓴다 |
| 눌려 있다 | '-어 있다' 구성. 피동 판별 문항으로 쓰지 않는다 |

- 피동·사동 형태가 같은 말(보이다, 읽히다, 안기다)은 **목적어 유무**로 가른다 (산이 보인다: 피동 / 사진을 보인다: 사동)

### 4-3. 이중 피동 (잘못된 피동)

- **정의: 피동 접미사(-이-/-히-/-리-/-기-)나 '-되다'가 붙은 말에 다시 '-어지다'를 붙인 것**
  - 잊혀지다(잊히다 + -어지다), 보여지다, 쓰여지다, 믿겨지다, 열려지다, 담겨지다, 바뀌어지다, 되어지다(-되다 + -어지다)
- **이중 피동이 아닌 것**
  - 올려지다 = 올리다(타동사) + -어지다 → 정상적인 피동. '명단에 올려져 있다'는 바른 문장
  - 나타나지다 = 자동사에 '-어지다' → 불필요하고 어색한 표현이지만 이중 피동은 아니다. 이중 피동 문항에 넣지 않는다
  - '-지게 되다' = 피동 표현 + '-게 되다'. 학교문법의 이중 피동이 아니다. 넣으려면 '불필요한 피동'이라는 별도 유형으로 이름 붙인다
- 교정 예시는 반드시 바른 문장이어야 한다 ('올려 있다' ×)
- 정문 쪽에 정상적인 '-어지다'(만들어졌다, 지워졌다)를 섞어 '-어지다만 보면 오답'이라는 전략을 막는다

## 5. 한글 창제 원리

| 구분 | 내용 |
|---|---|
| 자음 기본자 | ㄱ ㄴ ㅁ ㅅ ㅇ — **발음 기관의 모양을 본떴다(상형)** |
| 가획자 | ㅋ / ㄷ ㅌ / ㅂ ㅍ / ㅈ ㅊ / ㆆ ㅎ — 소리가 세지는 데 따라 획을 더했다 |
| 이체자 | ㆁ ㄹ ㅿ — 소리가 세지는 것에 따라 획을 더한 것이 아니라 모양을 달리해 만들었다 【설명 문구는 교과서 확인】 |
| 모음 기본자 | · ㅡ ㅣ — 하늘·땅·사람을 본떴다 |
| 초출자 | ㅗ ㅏ ㅜ ㅓ |
| 재출자 | ㅛ ㅑ ㅠ ㅕ |
| 창제·반포 | 1443년 창제, 1446년 반포, 28자 |

- **상형은 기본자 다섯 자의 제자 원리다.** 가획자에 "어떤 발음 기관의 모양을 본떴나요?"라고 묻지 않고 "어느 기본자에서 나왔나요?"로 묻는다. 이체자는 훈민정음 해례 제자해가 ㄹ·ㅿ도 혀·이의 모양을 본떴다고 서술하므로 '본뜨지 않았다'고 단정하지 않는다
- 이체자 설명은 교과서 문구 **한 가지로** 통일한다. 게임마다 "획을 더하기는 했지만"과 "획을 더하는 원리를 따르지 않고"처럼 다르게 쓰지 않는다 【교과서 문구 확인】
- 소리 분류 이름은 표준 표기로: 어금닛소리, 혓소리, 입술소리, 잇소리, 목소리. ㄹ은 **반혓소리**, ㅿ은 **반잇소리**
- 모아쓰기 비교는 **영어 알파벳(풀어쓰기)과 한글(모아쓰기)**로 한다. 일본 가나는 음절 문자라 풀어쓰기·모아쓰기 비교에 쓰지 않는다

## 6. 논증

### 6-1. 논증 방법

| 방법 | 정의 | 결론의 성격 |
|---|---|---|
| 연역 | 일반적 원리(전제)에서 구체적 결론을 끌어낸다 | 전제가 참이면 결론도 반드시 참(필연적) |
| 귀납 | 여러 구체적 사례에서 일반적 결론을 끌어낸다 | 개연적. **사례가 적거나 치우치면 성급한 일반화** |
| 유추 | **두 대상의 유사성을 근거로** 한 대상에서 확인한 것을 다른 대상에도 적용한다 | 개연적 |

- **유추를 "구체에서 일반으로의 추론"이라고 정의하지 않는다.** 그것은 귀납이다
- 귀납의 모범 예로 **사례 두 개**짜리 문항을 쓰지 않는다. 논증의 오류 게임은 같은 구조를 성급한 일반화로 가르친다. 귀납 예시는 사례를 여럿 들고, 해설에 "사례가 적으면 약하다"를 쓴다
- 결론이 개별 대상("우리 반도…")이면 유추에 가깝다. 귀납 문항으로 쓰지 않는다
- 숨은 전제가 빠진 연역은 "필연적"이라고 해설하지 않는다
- 【확인 필요】 교과서가 유추를 논증 방법 목록에 넣는지

### 6-2. 설(說)의 유추 구조

- 설은 **구체적 경험·사실 → (유사성으로) 다른 대상에 적용 → 삶의 이치(교훈)**로 전개된다
- 문항의 핵심은 **대응 쌍을 찾는 것**이다 (예: 이옥설 — 새는 서까래 ↔ 사람의 잘못 ↔ 나라의 정치)
- 경험의 주체를 정확히 쓴다 (슬견설의 출발 경험은 손님이 본 것, 주옹설은 주옹의 말)
- 원리에서 주장을 끌어내는 글(연역 구조)은 유추 예로 쓰지 않는다
- 원문 인용·요약은 원문 뜻을 바꾸지 않는다 (경설: "그 흐림을 취한다")

### 6-3. 논증의 오류

| 오류 | 핵심 판별 질문 |
|---|---|
| 성급한 일반화 | 몇 개의 사례로 전체를 말했나? |
| 흑백 논리(잘못된 이분법) | 가능성이 둘뿐이라고 전제했나? |
| 피장파장 | 상대도 같은 잘못을 했다는 것으로 비판을 피했나? |
| 논점 일탈 | 논의 주제와 다른 이야기로 결론을 냈나? |
| 순환 논증 | 결론을 전제에 그대로 넣었나? (근거가 결론을 바꿔 말한 것뿐인가?) |
| 인신공격 | 주장이 아니라 사람을 공격했나? |

- 【확인 필요】 교과서가 다루는 오류 목록 (부적절한 권위, 대중에 호소, 잘못된 인과, 동정에 호소 등이 들어가는지)
- **한 예문이 두 오류에 걸치면 문항에서 빼거나**, 경계 문항으로 쓰고 해설에 "왜 A가 아니라 B인가"를 쓴다
  - 사례 하나로 원인까지 단정 → 성급한 일반화이면서 잘못된 인과
  - 불쌍한 사정을 근거로 주장 → 동정에 호소 (목록에 없으면 논점 일탈로 처리할지 교사 확인)
  - "~하지 않으면 반드시 병에 걸린다" → 이분법보다 근거 없는 인과 단정
- 근거가 제시된 문장("거짓말을 안 하니까 믿을 수 있다")은 순환 논증 예로 쓰지 않는다
- 오류의 예라도 특정 집단 고정관념(성별·혈액형·종교·가정 형태)을 되풀이하지 않는다

## 7. 말하기·듣기

### 7-1. 설득 전략

| 전략 | 기준 |
|---|---|
| 이성적 설득 | 논리적 근거(사실, 통계, 전문가 의견, 인과 설명)로 설득 |
| 감성적 설득 | 청중의 감정(공감, 두려움, 희망)에 호소 |
| 인성적 설득 | 화자의 인품·전문성·경험에서 오는 신뢰로 설득 |

- **숫자가 있다고 이성적, '저는'으로 시작한다고 인성적이 아니다.** 숫자 없는 이성적 설득, '저는'으로 시작하는 감성적 설득을 섞는다
- 개인 경험 고백은 감성적·인성적 모두로 읽힐 수 있다. 판정 문항에서 빼거나, 문항에 판단 근거("화자의 신뢰를 높이는가, 청중의 감정을 움직이는가")를 밝혀 한쪽으로만 읽히게 고친다
- 통계 수치는 실제 출처가 있거나 '가상 자료'라고 밝힌다
- 연설 본문 안에 교과서 해설 문장을 섞지 않는다

### 7-2. 준언어와 비언어

| 준언어 (말소리에 딸린 것) | 비언어 (말소리 밖의 것) |
|---|---|
| 억양, 어조, 높낮이, 성량(크기), 속도, **쉼(말을 멈춤)** | 표정, 시선, 몸짓, 손짓, 자세, 옷차림, 청중과의 거리 |

- **말을 멈추는 쉼은 준언어다.** '잠시 기다렸다가'처럼 쉼과 시선·동작이 한 문장에 같이 있으면 판정 문항에서 빼거나 둘 다 들어 있다고 해설한다
- '목소리를 높이다'는 높낮이인지 크기인지 밝혀 쓴다
- 준언어 문항과 비언어 문항의 비율을 맞춘다 (9:1 금지)

## 8. 문학

### 8-1. 비평의 관점

| 관점 | 근거 |
|---|---|
| 표현론 | 작가 (생애, 창작 의도, 체험) |
| 반영론 | 현실 (사회·역사·시대 상황) |
| 효용론 | 독자 (감동, 깨달음, 영향) |
| 절대론(내재적 관점) | 작품 자체 (구조, 표현, 운율, 시점) |

- 반영론의 '현실' 범위를 하나로 정한다: **창작 당시의 현실**만인지, **작품이 그리는 시대 현실**도 포함하는지 【교과서 정의 확인】. 한 게임 안에서 섞어 채점하지 않는다
- 절대론 문항을 "완결성이 뛰어나다" 같은 칭찬으로만 끝내지 않는다. 비판적 평가도 절대론이 될 수 있다
- 관점마다 문장 첫머리·끝맺음을 고정하지 않는다 (작가 이름으로 시작 = 표현론, "깨달았다"로 끝 = 효용론 금지)
- 한 비평문에 두 관점이 섞인 경계 문항을 둔다
- 지어낸 비평문의 해설은 그 비평문에 있는 내용만 근거로 삼는다

### 8-2. 갈등의 유형

| 유형 | 기준 |
|---|---|
| 내적 갈등 | 한 인물의 마음속 대립 |
| 인물과 인물 | 두 인물의 목표·가치 충돌 |
| 인물과 사회 | 제도, 관습, 계층, **전쟁 같은 시대 상황** |
| 인물과 운명 | 인간의 힘으로 어쩔 수 없는 초월적 힘이나 타고난 운명 |
| 인물과 자연 | 자연재해, 맹수, 험한 자연환경 |

- **전쟁·가난·신분 제도는 사회 갈등으로 판정한다** 【교과서 확인】. 게임마다 운명과 사회를 섞어 판정하지 않는다
- 장애를 '운명과의 갈등' 예로 쓰지 않는다
- 예문에 유형 이름이나 그 동의어(굴레, 마음속 고민, 태풍)를 박아 두지 않는다. 교과서 소설 발췌를 늘린다
- 인물 정보는 정확히 쓴다 (홍길동은 양반 아버지의 서자)

### 8-3. 원작을 쓰는 게임

- 원작에 없는 장면·선택지·대사는 그 자리에서 '게임 설정(원작에 없음)'으로 표시한다
- 원작의 주제와 반대로 가는 결말을 만들지 않는다
- 원작 사실(인물, 장소, 사건 순서)은 교과서 본문과 대조한다
- 서술자·시점이 학습 목표인 작품(「사랑손님과 어머니」의 어린 관찰자 서술자 등)은 시점을 바꾸는 게임을 만들 때 원래 시점과 비교하는 장치를 넣는다

## 9. 쓰기

### 9-1. 설명문의 처음

- 역할 이름은 교과서 용어를 쓴다: 화제 제시, 흥미 유발, 글을 쓰는 목적(동기), 앞으로의 내용 안내 【교과서 용어 확인】. 교과서에 없는 이름('배경 정보' 등)을 만들지 않는다
- 질문 문장의 판정 기준을 하나로 정한다: 질문 속 내용이 **본문에서 다룰 내용이면 내용 안내**, 독자의 관심을 끄는 데 그치면 흥미 유발. 모든 문항에 같은 기준을 적용한다
- 본문에서 다룰 내용(종류, 방법)을 '처음'의 문장으로 넣지 않는다
- 모든 예시 글을 같은 구조(흥미 → 정의 → 안내)로 만들지 않는다

### 9-2. 복합양식 자료

- 글 유형과 구성을 일치시킨다 (기사문이면 표제·부제·전문·본문, 일반 글이면 처음·중간·끝)
- CC0는 "저작권이 없는"이 아니라 **"저작권자가 법이 허용하는 범위에서 권리를 포기한"** 자료
- 자료 위치(처음·중간·끝) 판정은 한 가지만 정답으로 두기 어려운 경우가 많다. 자료의 쓰임(관심 끌기인지, 근거인지)을 문항에 밝혀 정답이 하나가 되게 하거나 문항을 뺀다

## 10. 어휘 (문학 작품 어휘 게임)

- 동음이의어는 **작품에 쓰인 뜻**으로 풀이한다 (상호: 가게 이름 = 商號 / 장사하는 집 = 商戶, 「일용할 양식」의 양식 = 糧食)
- '가짜 뜻풀이' 문항에서 사전에 있는 맞는 뜻을 가짜로 쓰지 않는다 (구실 = 핑계, 口實)
- 뜻이 거의 같은 말(악착스럽다/억척스럽다, 영세하다/옹색하다)을 한 문항의 보기에 함께 넣지 않는다
