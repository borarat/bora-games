2. **개념표 운명 설명** (210행): '불치병' 뺌.
3. **성취기준** (199행): (2022) [9국05-02] 갈등의 진행과 해결 과정을 파악하며 작품을 감상한다.
4. **점수 v3** (439~444행): 첫 시도 +10, 다시 풀어 맞힘 +5(전에는 0점), 오답 −5, 콤보 3~4번째 +5·5번째부터 +10. 단계 만점 270점(성장 이모지·결과 화면·리포트 모두 이 숫자).
5. **기록** — 결과 계산을 calcStats() 하나로(460행). 결과 화면·리포트 JPG·오답노트·앱스크립트 전송이 모두 이 값을 씀.

   - 미응답은 오답으로 세지 않고 따로 표시, 미응답이 있으면 "끝까지 풀지 않았어요 (n문항 남음)"

7. **소감 선택** (725행): 이름만 있으면 저장됨.
8. **옛 게임 표준**: 앱스크립트 연동(398행, 쓰기 윤리 수사대와 같은 주소·학번·이름 인증·시작 알림·결과 전송), 개인정보 안내 오프라인/온라인 두 가지(289~299행), 키보드(613행: Enter·Space·→ 다음 — 채점이 끝난 문항에서만, 오답 때 Enter·Space = 다시 풀기, ← 이전), '게임 종료' 확인 창(598행, 남은 문항 수 표시), 시작 화면 크레딧에 최종 수정 시각·게임 코드 L101(220행).

## 교사에게 묻는 것
1. **'천재지변'은 운명 예로 쓰지 않았습니다.** 기준표 8-2에서 자연재해는 '인물과 자연'이라, 천재지변을 운명 정답으로 두면 같은 게임 안의 태풍·화산(자연) 문항과 부딪힙니다. 대신 예언·신탁·저주·타고난 별자리로 썼습니다. 천재지변도 운명으로 가르치시려면 말씀해 주세요.
2. 새 운명 문항 6개(위 표) 문장과 난도가 괜찮은지 봐 주세요. 특히 3-8(신탁과 손자)은 '인물 vs 인물'과 헷갈릴 수 있는 경계 문항으로 일부러 넣었습니다(3단계 '경계선상 문항 포함' 설명에 맞춤).
3. 점수 기본점을 **10점**으로 했습니다(5지선다, 단계 만점 270). 15점을 원하시면 바꿔 드립니다.
4. 게임 코드는 시작 화면 맨 아래 크레딧 줄에 "게임 코드 L101"로 넣었습니다. 본보기로 삼은 '쓰기 윤리 수사대'·'말의 온도를 바꿔라'는 시작 화면에 코드를 따로 보여 주지 않아 이렇게 했습니다.
5. '틀린 문제 다시 보기'와 오답노트에 **다시 풀어 맞힌 문항도** 넣었습니다(전송하는 wrongItems와 같게). 못 맞힌 문항만 원하시면 말씀해 주세요.
