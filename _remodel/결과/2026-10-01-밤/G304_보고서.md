## 한 줄 요약
**다 됨.** 9차_B-A '고칠 것' 전부와 교사 결정(G304, 시간 순서의 '-고' = 종속, '-고' 붙임표 답 인정)을 반영했습니다.

## 고친 것 (줄 번호는 고친 뒤 기준)
1. **'-고 = 대등' 단정 고침**: 개념표 나열 칸(259) "-고 (앞뒤 절을 나란히) · 시간 순서의 -고는 종속", 2단계 1번 해설(463).
   - 교사 결정 "시간 순서의 '-고' 문항은 정답·해설을 종속으로": 30문항 전부 확인했는데 **시간 순서의 '-고'를 쓴 문항은 없습니다**('-고' 문항 4개 — 1단계 1·6번, 2단계 1번, 3단계 1번 — 모두 나열). 그래서 정답을 바꾼 문항은 없고 해설·개념표만 고쳤습니다.
2. **2단계 9번** (478~479): "…마음대로 해라" → "축구를 하든지 농구를 하든지 해라.", 해설도 선택으로.
3. **3단계 10번 교체** (512~514): "밤을 새우니 오늘 졸리다" → "날이 추우니 옷을 두껍게 입어라."
4. **채점**
   - 1단계 빈칸(717): 붙임표·괄호·공백·끝 마침표를 지우고 비교. "-고", "(으)러", "고." 모두 정답.
   - 1단계 6번(445): "나는 밥을 먹었고 동생은 빵을 먹었다" 인정. 7~10번은 시제 선어말 어미를 붙이면 문장이 어색해져(맑았어서·보았거나·만났으려고·높았으면 → 뜻이 바뀌거나 비문) 추가하지 않음.
5. **점수 v3** (421~423, 770~): 정답 +10, 오답 −5(하한 0), 콤보 3·4번째 +5, 5번째부터 +10. 단계 만점은 5-4 공식으로 계산(`stageMax`) → 10문항 **170점**. 시작 화면 점수 안내(268)·결과 화면 "만점 170점"·리포트·오답노트가 같은 값. 쓰이지 않던 틀린 maxScore(1150) 삭제.
6. **기록**
   - '게임 종료'(825): 확인 창을 띄우고, 안 푼 문제는 미응답으로 남김(전: 오답).
   - `calcStats()`(833) 하나로 결과 화면·리포트·오답노트·전송 계산. 총평은 첫 시도 정답률(846 `verdict`, 5-2 표 문구), 미응답이 있으면 "끝까지 풀지 않았어요 (n문항 남음)", 채점 0개면 "풀어 본 문제가 없어요".
   - 결과 칸: 첫 시도 정답 · 못 맞힘 · 미응답 · 최고 콤보 + 첫 시도 정답률. (이 게임은 다시 풀기가 없어 '다시 풀어 맞힘' 칸은 넣지 않음)
   - 오답 목록·오답노트에 미응답 문항도 '미응답'으로.
7. **소감 선택** (930): 이름만 있으면 저장 버튼 켜짐. 소감이 비면 리포트에 "(소감 없음)".
8. **입력 이벤트 중복 제거**: showComplete 안에서 붙이던 리스너를 페이지 처음에 한 번만 붙임(1113~).
9. **키보드** (1125~): 게임 중에만. 채점이 끝난 문제에서 Enter·Space·→ = 다음, ← = 이전. 답하기 전에는 넘어가지 않음. 1단계 입력칸 Enter는 제출만.
10. **성취기준** (247): `(2015) [9국04-06] 문장의 짜임과 양상을 탐구하고 활용한다.` / `(2022) [9국04-04] 문장의 짜임을 이해하고 표현 효과를 고려하여 문장을 구성한다.`
11. **앱스크립트 연동** (381~419 설정·함수, 295 학번·이름 창, 535 doLogin, 853 sendResult, 1113~ 온라인 개인정보 안내): W301·G301과 같은 endpoint·흐름.
12. 제작 정보에 `최종 수정 2026.10.01 21:00 · 게임 코드 G304`(281), 맨 위 리모델링 주석(3~7행).

## 검증 결과
Playwright(chromium, file://, 외부 요청 차단). pageerror 없음(오프라인·연동 모두).
- 1·2·3단계를 화면 클릭·입력으로 끝까지 정답 풀이, 문제마다 Enter로 다음 이동: 세 단계 모두 170점, "만점 170점", 정답률 100%, "완벽해요!".
- 빈칸 정규화: "-고", "고", "(고)", " 고 ", "고.", 5번 "-(으)러", 4번 "-면" 정답 / 2번 "어서" 오답. 6번 "먹었고" 정답.
- 키보드: 답하기 전 Enter·Space·→ 눌러도 1번 그대로.
- 섞어 풀기(3단계: 정답 1, 오답 1, 나머지 안 풂 → 게임 종료 확인): 점수 5(10−5), 결과 1/1/8, 정답률 50%(1/2), "끝까지 풀지 않았어요 (8문항 남음) · 기본은 잡혔어요". 리포트 유형별(대등-나열 1/1, 대등-대조 0/1, 나머지 '미응답')이 같은 함수 값. 리포트·오답노트 JPG 내려받아 확인.
- 게임 종료 확인 창에서 '취소' → 게임 계속.
- 아무것도 안 풀고 종료: "풀어 본 문제가 없어요".
- 이름만 입력 → 저장 버튼 켜짐.
- 연동(`?key=TEST`, 서버 응답 가짜): verify·start·submit 전송. 2단계 5번만 틀리고 끝까지 → `gameCode:"G304"`, score 115(콤보 계산 맞음), correctCount 9, answeredCount 10, wrongItems "5". 전송 완료 문구, 이름칸 자동 채움·잠금.
- 독립 검토: 코디네이터가 따로 실행(이 보고서 작성 시점에는 미실행).

## 교사에게 묻는 것
1. **시간 순서의 '-고' 문항이 이 게임에 없습니다.** 교사 결정(종속)을 연습시키려면 문항을 새로 넣어야 하는데, 2단계 종속 세부 유형이 원인·조건·목적 셋뿐이라 '시간(순서)' 유형을 새로 만들어야 합니다. 넣을까요? (예: 2단계 "밥을 먹고 학교에 갔다" → 종속-시간)
2. 3단계 10번 새 문장에서 보기 '-(으)면'을 넣으면 "날이 추우면 옷을 두껍게 입어라"도 자연스러운 문장이 됩니다. 발문에 '종속-원인'이 나와 있어 정답은 '-(으)니' 하나지만, 헷갈리면 보기 '-(으)면'을 '-(으)러' 등으로 바꿀 수 있습니다.
3. 점수 기본점을 10점으로 했습니다(만점 170). 15점을 원하시면 바꿔 드립니다.
4. 게임 코드는 시작 화면 제작 정보 줄에 "게임 코드 G304"로 넣었습니다.

## 추가로 발견한 것 (고치지 않음)
- **3단계(보기 4개)에 다시 풀기가 없습니다.** 지침 3-6·5-1은 보기 3개 이상이면 재시도 1회(+절반 점수)지만, 9차 목록에 없어 그대로 두었습니다.
- 1단계 1번 "인생은 짧고 예술은 길다"는 뜻으로 보면 대조에 가깝지만 '대등-나열'로 분류되어 있습니다(대등인 점은 맞음).
- 오답노트 JPG에서 '내 답'과 '정답' 두 줄이 붙어 있고 상자 아래에 거의 닿습니다(읽을 수는 있음).
- 리포트 JPG의 점수(큰 글자)가 오른쪽 위 제목 줄과 가깝습니다. '학습 시간 약 0분'처럼 1분 미만은 0분으로 나옵니다.
- 문항 수 10이 코드 여러 곳에 하드코딩(진행 표시·배열 길이).
