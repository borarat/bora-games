2. **절의 주어까지 밑줄** — 2단계 3번(392), 7번(400), 3단계 7번(435), 12번(445). 해설의 인용 부분도 같이.
3. **조사 붙임표 삭제** — 개념 칸 인용절(223), 1단계 10번 힌트·해설(380~382), 3단계 5번 힌트·해설(431~432), 3단계 15번 힌트(452). 3단계 10번 힌트의 "-라고"(442)도 같은 문제라 '라고'로 고쳤습니다(목록에 위치는 없었지만 같은 항목).
4. **서술형 채점 정규화** (496행 `norm`): 공백을 모두 지우고, 끝 마침표와 둥근 따옴표(“ ”)를 맞춘 뒤 비교. '?'로 끝나면 여전히 오답.
5. **1단계 맞는 답 인정**: 5번 '엄마가 만드신'(365), 10번 직접 인용 `선생님이 "내일 시험이 있다."라고 말씀하셨다`(380, 마침표 없는 것도). 두 해설에 "이것도 맞아요" 한 문장 추가.
6. **오답 목록·오답노트 JPG에 물은 부분 「 」 표시** (728 `markU`, 목록·노트 둘 다).
7. **기록**
   - '게임 종료'(651): 안 푼 문제는 미응답으로 남김(전: 오답). 확인 창 문구도 "미응답으로 기록됩니다". 첫 시도에 틀리고 다시 풀지 않은 문제는 '못 맞힘'.
   - 결과 계산을 `calcStats()`(686) 하나로: 결과 화면·리포트 분야별 정답률·오답노트·앱스크립트 전송이 모두 이 값을 씀. 분야별 정답률은 **첫 시도 정답 ÷ 채점된 문항**(재시도 정답 제외, 미응답 제외).
   - 총평(702 `verdict`)은 정답률 기준(5-2 표 문구). 미응답이 있으면 "끝까지 풀지 않았어요 (n문항 남음)"을 앞에, 채점 0개면 "풀어 본 문제가 없어요".
   - 결과 칸: 첫 시도 정답 · 다시 풀어 맞힘 · 못 맞힘 · 미응답 · 최고 콤보 + 첫 시도 정답률.
   - 오답 목록·오답노트에 미응답 문항도 '미응답'으로 넣음.
8. **오답노트·리포트 버튼은 이름만 있으면 켜짐** (741). 소감이 비면 리포트에 "(소감 없음)".
9. **성취기준** (203): `(2015) [9국04-06] 문장의 짜임과 양상을 탐구하고 활용한다.` / `(2022) [9국04-04] 문장의 짜임을 이해하고 표현 효과를 고려하여 문장을 구성한다.` (G302와 같은 문구)
10. **앱스크립트 연동** (308~343 설정·함수, 240 학번·이름 창, 505 doLogin, 709 sendResult, 801 온라인 개인정보 안내): W301·G301과 같은 endpoint·흐름. `?key=` 없으면 오프라인 그대로.
11. 시작 화면 제작 정보에 `최종 수정 2026.10.01 21:00`, `게임 코드 G303` 추가(235). 파일 맨 위 리모델링 주석(3~8행).
12. 리포트 JPG: 점수 줄과 통계 줄이 구분선과 겹쳐 위치만 조정.

## 검증 결과
Playwright(chromium, file://, 외부 요청 차단). pageerror 없음(오프라인·연동 모두).
- 1·2·3단계를 처음부터 끝까지 정답으로 풀어 결과 화면까지: "완벽해요!", 첫 시도 정답률 100%, 목록 "틀리거나 남긴 문제가 없어요".
- 정규화: "농사가 잘 되기", 두 칸 띄운 전체 문장, "서술 절", "엄마가 만드신", 직접 인용(곧은 따옴표·둥근 따옴표), 간접 인용 모두 정답. "엄마가 만든?"·"엄마가 만들"은 오답.
- 섞어 풀기(2단계: 첫 시도 정답 1, 다시 풀어 맞힘 1, 다시 풀어도 틀림 1, 틀리고 다시 안 풂 1, 나머지 11개 안 풂 → 게임 종료): 결과 1/1/2/11, 정답률 25%(1/4), 총평 "끝까지 풀지 않았어요 (11문항 남음) · 다시 한 번 도전해요". 리포트 분야별 값이 같은 함수 값과 일치(목적어 1/1, 주어 0/1(재시도 정답은 제외), 서술어 '미응답').
- 오답 목록·오답노트 JPG에 「할머니가 직접 짜신」처럼 물은 부분 표시, 미응답 문항은 '미응답' 표시. 리포트·오답노트 JPG 내려받아 눈으로 확인(잘림 없음).
- 아무것도 안 풀고 종료: "풀어 본 문제가 없어요"(칭찬 문구 없음).
- 이름만 입력 → 오답노트·리포트 버튼 켜짐.
- 키보드: 답하기 전 Enter·Space → 넘어가지 않음. 답한 뒤 Enter → 다음.
- 연동(`?key=TEST`, 서버 응답 가짜): 시작 → 학번·이름 창 → verify·start 전송, 1단계 끝까지(3번 오답 후 다시 풀어 맞힘) → submit 전송 `gameCode:"G303"`, correctCount 9, answeredCount 10, skippedCount 0, wrongItems "3". "결과가 선생님께 전송되었습니다" 표시, 이름칸 자동 채움·잠금, 온라인 개인정보 안내로 바뀜.
- 독립 검토: 2가지 지적 → 모두 고침. 고친 뒤 Playwright 재검증

## 추가로 발견한 것 (고치지 않음)
- 개념 칸 관형절 "-는, -(으)ㄴ"에 기준표의 '-(으)ㄹ, -던'이 없고, 명사절 "-기, -음 → 주어·목적어 역할"은 표지를 '-(으)ㅁ'으로 쓰지 않음.
- 리포트 JPG 분야별 막대가 0%일 때 막대 왼쪽 끝에 작은 색 삼각형이 그려짐(너비 0에 둥근 모서리를 그려서).
- 점수 규칙은 '고치지 말 것'에 따라 +100/−30/콤보 +20·+50, 재시도 +50 그대로입니다(v3 점수 규칙과 다름). 만점 숫자는 화면에 없습니다.
- 1단계 서술형도 재시도 1회가 있습니다(지침 3-6은 보기 3개 이상만 재시도라 하지만, 서술형이라 그대로 둠).
